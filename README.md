# Java_Learning-Agent
一款基于 Ollama 的**本地离线 Java 学习 AI 助手**，内置可视化 GUI 界面，所有 AI 推理在本地完成，无需联网调用云端接口，轻量化、隐私安全，专为 Java 零基础学习者打造。

## 项目简介
本工具集成 **Java 代码纠错、知识点问答、错题本收纳、刷题练习** 四大核心功能。
V2 版本大幅优化使用体验，解决手动启动 Ollama、输出格式乱码等痛点，降低新手使用门槛。

## ✨ 版本功能说明
### 🔹 V1 基础功能
1. **代码智能纠错**
粘贴存在语法/逻辑错误的 Java 代码，自动定位问题、给出修正方案，并搭配通俗讲解。
2. **知识点问答**
自由提问 Java 基础知识点，AI 结合示例代码讲解，标注常见易错点。
3. **错题本**
本地数据库持久保存代码错题，支持随时查看历史记录。
4. **基础刷题**
支持自定义题目练习，AI 逐题解析。

### 🔹 V2 新增 & 优化（当前版本）
1. **自动托管 Ollama 服务**
程序启动自动检测并后台拉起 Ollama，关闭软件自动终止进程，**无需手动运行启动脚本**。
2. **双重文本过滤**
自动清除 Markdown 格式符号（```、#、`、* 等），界面展示整洁无乱码。
3. **窗口状态记忆**
自动保存窗口大小、位置，下次打开保持上一次布局。
4. **界面交互优化**
简化按钮逻辑，支持一键清空输入/输出内容。
5. **全功能兼容**
保留 V1 所有原有业务逻辑，平稳迭代升级。

## 📦 环境依赖
- Python 3.8+
- Ollama（本地大模型客户端）
- 依赖库：
  ```txt
  PyQt6

  ```

## 🚀 部署 & 启动教程
### 1. 前置准备
1. 安装 [Ollama](https://ollama.com/) 并配置系统环境变量
2. 拉取基础模型（终端执行）
   ```bash
   ollama pull qwen2.5:3b
   ```

### 2. 安装 Python 依赖
进入项目根目录，执行：
```bash
pip install -r requirements.txt
```

### 3. 运行程序
终端启动指令：
```bash
python main.py
```
> 启动后自动后台运行 Ollama 服务，直接使用界面即可。

## ⚠️ 常见问题排查
1. **11434 端口连接失败**
   检查 Ollama 是否正常安装并加入环境变量，重启程序重试。
2. **AI 输出出现代码块/符号乱码**
   当前版本已内置格式过滤，若仍出现可清空输入重新提问。
3. **Python 依赖缺失**
   重新执行 `pip install -r requirements.txt` 安装全部依赖。
